# orv-aov-vergelijker

Vergelijker voor adviseurs — goed voor de klant, goed voor de adviseur. Standalone voorwaardenvergelijker (één HTML-bestand, geen build-step, geen externe API's) voor ORV, woonlasten/AO en inkomensverzekeringen van TAF, BNP Paribas Cardif en Credit Life. Peildatum 12-11-2026.

Open `index.html` in de browser. Hulpmiddel voor de adviseur: ondersteunt het advies, vervangt het niet. Geen premievergelijking.
