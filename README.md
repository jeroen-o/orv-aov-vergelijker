# orv-aov-vergelijker

Standalone voorwaardenvergelijker (één HTML-bestand, geen build-step, geen externe API's) voor ORV, woonlasten/AO en inkomensverzekeringen van TAF, BNP Paribas Cardif en Credit Life. Peildatum 12-11-2026.

Open `index.html` in de browser. Interne vergelijking; geen advies en geen premievergelijking.
